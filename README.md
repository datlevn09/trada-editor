# Bộ dựng video Trà Đá

Trà Đá Editor và Kho mẫu dựng video, chạy trên máy, dùng cùng Claude Code. Tặng miễn phí.

## Tải về

Vào mục **[Releases](../../releases/latest)** và tải `qua-trada-dung-video-x.y.z.zip`, rồi giải nén vào thư mục skill của Claude Code (`~/.claude/skills/`).

## Gồm gì

- **Trà Đá Editor** — trình chỉnh video tiếng Việt chạy trên máy, kéo tay chỉnh chữ, hình, nhịp, xuất MP4. Không gửi file đi đâu.
- **Kho mẫu** — mẫu dựng "trước/sau": đưa clip gốc và clip đã dựng vào, ra video có hook, nhịp đổi hình và lời kêu gọi.

## Cần gì

Windows 10/11 hoặc macOS 13 (Ventura) trở lên, Node 20+, ffmpeg, Claude Code. Lần chạy đầu tải thêm HyperFrames (~400 MB).

## Giấy phép

Tặng để dùng và sửa cho nhu cầu của bạn. Không bán lại bộ công cụ này. Thành phần bên ngoài giữ giấy phép gốc: HyperFrames (Apache-2.0), GSAP, Be Vietnam Pro (OFL) — xem `THIRD-PARTY.md` trong gói.
